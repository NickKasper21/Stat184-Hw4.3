# Stat184-Hw4.3
Practice repository for STAT 184 class for HW 4.3 

## What is the Project 
Homework 4.3 was all about being able to tidy, wrangle, and graph data to display information. All of this had to be in a single Quarto document that anyone can check. 

## Where did everything come from
- Diamonds data came from the ggplot2 R package
- Big Ten Women's Basketball data comes from teams.csv and team_box.csv from the Big Ten Academic Alliance data
- The calcium data set was provided as part of the assignment (calcium.csv)
- Monte Carlo data was randomly generated by R
